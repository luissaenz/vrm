## ⚠️ Critical Warnings

### Don't Lose These!
1. **Android Keystore File** (`.jks`)
   - If lost, you can't update your app
   - Backup in multiple secure locations
   - Never commit to Git

2. **Signing Credentials**
   - Store in password manager
   - Keep offline backup
   - Document recovery process

3. **Apple Developer Account**
   - Renew annually ($99/year)
   - If lapses, app is removed from store

### Common Mistakes
- ❌ Publishing without testing on physical devices
- ❌ Incomplete privacy policy or data safety form
- ❌ Using debug logging in production
- ❌ Not incrementing build number for resubmission
- ❌ Submitting on weekends (delays review)
