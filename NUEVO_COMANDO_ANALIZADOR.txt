🔍 QUÉ ES
─────────────────────────────────────────────────────────────────────────────
Transformación de ANALISIS.txt en un comando interactivo que:

✅ Pide documento a analizar (cualquiera)
✅ Pide sección específica (cualquiera)
✅ Ejecuta análisis exhaustivo (10 secciones siguiendo ANALISIS.txt)
✅ GUARDA en carpeta ORIGINAL del documento
✅ Versionado automático: (1), (2), (3), etc.
✅ NO sobrescribe archivos existentes


🚀 CÓMO USAR
─────────────────────────────────────────────────────────────────────────────

En Claude Code o Antigravity IDE:

  /Analizador

Responde 3 preguntas:

  1️⃣ ¿Documento a analizar?
     → docs/mvp-Definition.md

  2️⃣ ¿Qué sección?
     → FASE 1

  3️⃣ ¿Confirmas?
     → SÍ

Sistema genera:
  ✓ Análisis de 10 secciones
  ✓ Guardado automáticamente
  ✓ En la carpeta del documento


📊 DÓNDE SE GUARDA
─────────────────────────────────────────────────────────────────────────────

DOCUMENTO:              ANÁLISIS GUARDADO:
─────────────────────────────────────────────────
docs/mvp.md      →     [seccion]-analisis-claude.md

FASE_1/Dia4-5/   →     FASE_1/Dia4-5/
especificacion         claude-analisis.md

any/path/doc.md  →     any/path/
                       claude-analisis.md

REGLA: Siempre en la MISMA CARPETA que el documento
