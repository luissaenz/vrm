📖 ARQUITECTURA
─────────────────────────────────────────────────────────────────────────────
5 ROLES:

  1. ANALIZADOR
     └─ Valida que documento técnico sea completo y consistente
     
  2. IMPLEMENTADOR  
     └─ Genera código completo y compilable
     
  3. VALIDADOR
     └─ Code review exhaustivo contra especificación
     └─ Detecta issues (críticos, importantes, mejoras)
     
  4. CORRECTOR
     └─ Arregla issues detectados
     └─ Máximo 3 loops automáticos
     
  5. ORQUESTADOR (automático)
     └─ Coordina el flujo entre roles

FLUJO:
  ANALIZAR → IMPLEMENTAR → VALIDAR → ¿APROBADO?
                                      ├─ SÍ → FIN ✅
                                      └─ NO → CORRECTOR → (repite)
