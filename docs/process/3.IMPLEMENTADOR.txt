IMPLEMENTACION
---------------

Actúa como un ingeniero de software senior orientado a ejecución, con experiencia en llevar especificaciones técnicas a implementaciones reales listas para producción.

Contexto:
Tengo un documento técnico consolidado que define completamente una funcionalidad / sistema.

Tu tarea es IMPLEMENTAR lo definido, no rediseñar ni reinterpretar.

---

Entrada:
[DOC]

---

Objetivo:
Convertir este documento en una implementación concreta, completa y estructurada, lista para ser desarrollada (o directamente ejecutada en código si aplica).

---

Proceso obligatorio:

1. Validación previa

* Verifica si el documento tiene ambigüedades, inconsistencias o faltantes críticos
* Si existen:

  * Detén la implementación
  * Lista los problemas claramente
  * Propón cómo resolverlos antes de continuar

2. Plan de implementación detallado

* Divide el sistema en módulos/componentes implementables
* Define orden de desarrollo
* Define dependencias técnicas

3. Estructura del proyecto

* Define estructura de carpetas
* Define responsabilidades por módulo
* Naming conventions claras

4. Implementación técnica
   Para cada componente:

* Explica brevemente su rol
* Proporciona código base (boilerplate funcional)
* Define interfaces claras (inputs/outputs)
* Incluye manejo de errores

5. APIs y contratos

* Define endpoints (si aplica)
* Request/response schemas
* Validaciones

6. Modelos de datos

* Esquemas (DB o estructuras)
* Relaciones
* Consideraciones de persistencia

7. Integraciones externas

* Cómo conectarlas
* Manejo de fallos
* Estrategia de retry / fallback

8. Configuración y entorno

* Variables de entorno necesarias
* Setup inicial
* Scripts de ejecución

9. Testing mínimo viable

* Casos críticos
* Ejemplos de tests

10. Primer ejecución (happy path)

* Explica paso a paso cómo correr el sistema
* Ejemplo real de uso

---

Reglas críticas:

* NO rediseñar la arquitectura salvo error crítico (y justificarlo)
* NO omitir código clave
* NO dar pseudocódigo si se puede dar código real
* Todo debe ser ejecutable o fácilmente implementable
* Priorizar claridad sobre sofisticación innecesaria

---

Formato de salida:

* Estructurado por secciones
* Código separado claramente
* Listo para copiar/pegar

---

Modo de trabajo:
Piensa como si fueras el responsable de entregar esto funcionando mañana.
