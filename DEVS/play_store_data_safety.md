- **In transit:** N/A (no data transmitted)
- **At rest:** Device-level encryption (dependent on device security)

### 4. Data Deletion
- User can delete projects, clips, and all data via app settings
- No server-side data to delete (100% local)

### 5. Security Practices
- [x] Data encrypted in transit (N/A — no transmission)
- [x] Data encrypted at rest (device-level)
- [x] User can request data deletion (via settings)

### 6. Data Sharing
**We do NOT share any personal data with third parties.**

### 7. Children's Privacy
- App not intended for children under 13
- No data collected from children knowingly
